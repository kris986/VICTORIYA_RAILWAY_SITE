# Сайт Виктории: рабочая папка для Railway

Поисковая подготовка и безопасный порядок открытия индексации описаны в [SEO_LAUNCH.md](SEO_LAUNCH.md). По умолчанию сайт остаётся с `noindex`; настройки для поискового запуска пока не включены.

Обновлено: 20 ноября 2026 года. Кристина сообщила о запуске сайта на собственном домене <https://www.vektortaro.com/>. Проверка 20 ноября подтвердила: `https://vektortaro.com/` перенаправляет на адрес с `www`, главная страница отвечает `200`, длительность 30–45 минут и ссылки на личные Telegram и Instagram Виктории опубликованы. Поисковая индексация пока закрыта метатегом `noindex,nofollow`; на основном домене `/robots.txt` и `/sitemap.xml` отвечают `404`. В локальных файлах после этой проверки кнопки мессенджеров настроены на открытие в новой вкладке, добавлена согласованная иконка Instagram в футер, уменьшен вес трёх иллюстраций Таро и установлен выбранный фавикон «Печать» в SVG и PNG. Эти новые правки и подготовленные серверные настройки SEO ещё не загружены на Railway — перед открытием индексации нужно обновить сервис сайта и проверить результат.

Эта папка содержит самостоятельную версию сайта. В `public/` лежат HTML, CSS и изображения; `server.mjs` отдаёт эти файлы на порту, который задаёт Railway. Бот, база данных, API-ключи и платёжные интеграции в пакет не входят. Кнопки Telegram и Instagram ведут в личные профили Виктории, без автоматической анкеты.

Сайт использует облегчённые JPEG-версии трёх карт Таро. Неиспользуемые исходные PNG и временные варианты иконок удалены из рабочей папки перед публикацией в GitHub.

## Ссылки на мессенджеры

По умолчанию сайт ведёт на `https://t.me/viktoria_tarotreader` и `https://www.instagram.com/viktoria_tarotreader`. Эти ссылки продолжают работать, если открыть `public/index.html` прямо с компьютера.

Для управления ссылками через Railway задайте в **Variables** сервиса сайта:

```text
TELEGRAM_URL=https://t.me/viktoria_tarotreader
INSTAGRAM_URL=https://www.instagram.com/viktoria_tarotreader
```

Если переменная не задана, остаётся адрес из HTML. `INSTAGRAM_URL` меняет и кнопку, и иконку в футере. Сервер читает переменные при запуске, поэтому после их изменения проверьте опубликованную страницу и оба перехода. Принимаются только HTTPS-ссылки на `t.me` и `instagram.com` соответственно; неверный адрес не позволит серверу запуститься. Эти ссылки публичны: посетитель видит их в странице, поэтому хранить здесь секреты нельзя.

## Что проверить при согласовании с Викторией

1. Проверить тексты, цены и фотографию. Они взяты из предоставленных материалов и уже доступны по публичной ссылке; построчное утверждение Викторией пока не зафиксировано.
2. Учесть, что домен уже публичный: страницу сможет открыть любой, у кого есть ссылка; метатег `noindex` не является защитой от просмотра.
3. Открыть страницу на компьютере и телефоне и проверить изображения, FAQ и кнопки. Такая визуальная проверка пока не зафиксирована.

Правки после замечаний Виктории вносить в эту папку. Макет в `output/viktoria-landing-draft/` и закрытый предварительный просмотр — история разработки, не источник дальнейших обновлений Railway. Перед повторной загрузкой проверить изменённую страницу локально и затем обновлять существующий сервис сайта, сохраняя его публичный адрес. Не загружать сайт в сервис личного Telegram-помощника.

## Загрузка через Railway CLI

Если CLI ещё не установлен на Mac, установите его командой `brew install railway` (или `npm i -g @railway/cli`). Для повторной загрузки из этой папки проверьте, что она связана с правильным проектом и именно сервисом сайта, затем выполните:

```sh
railway login
railway link
railway up
```

Команда `railway up --new` здесь не нужна: сайт уже развернут. При выборе сервиса не путайте его с сервисом личного Telegram-помощника.

Справка Railway: [связать папку с существующим проектом](https://docs.railway.com/cli/link) и [загрузить обновлённые файлы в сервис](https://docs.railway.com/cli/up).

Railway использует `Dockerfile` в корне этой папки. Для режима согласования дополнительные переменные окружения не нужны: сервер читает `PORT`, который задаёт Railway, и слушает `0.0.0.0`. Поисковая индексация включается позднее двумя настройками из [SEO_LAUNCH.md](SEO_LAUNCH.md).

После обновления откройте <https://www.vektortaro.com/> и проверьте нужные изменения. Технический адрес <https://victoriyatarot.up.railway.app/> тоже отвечает `200`; при открытии поисковой индексации важно не продвигать его как второй основной адрес. Если потребуется закрыть доступ к сайту, это отдельное решение и настройка; `noindex` для этого недостаточен.

## Локальная проверка

```sh
npm test
npm start
```

Откройте `http://localhost:3000`. Для проверки работы сервера доступен адрес `http://localhost:3000/healthz`.

## Ограничения текущей версии

- Сайт — черновик для согласования, не готовая клиентская воронка.
- Тексты, цены и право публикации фото ещё согласуются с Викторией.
- Переходы в Telegram и Instagram присутствуют в опубликованном HTML; ручная проверка открытия чатов на телефоне не зафиксирована.
- Сайт опубликован на собственном домене; поисковая индексация ещё выключена. Построчное утверждение текстов Викторией и полная визуальная проверка после запуска не зафиксированы.
