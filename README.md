# Сайт Виктории: пакет для Railway

Эта папка содержит самостоятельную версию чернового сайта для согласования. В `public/` лежат HTML, CSS и изображения; `server.mjs` отдаёт эти файлы на порту, который задаёт Railway. Бот, база данных, API-ключи и платёжные интеграции в пакет не входят. Кнопки Telegram и Instagram пока не ведут в клиентские сценарии и честно показывают это при нажатии.

## Что сделать перед отправкой Виктории

1. Проверить тексты, цены и фотографию. Они взяты из предоставленных материалов, но Виктория ещё не утвердила их для публичной страницы.
2. Решить вопрос с доступом. После создания публичного домена Railway сайт сможет открыть любой, у кого есть ссылка; метатег `noindex` не является защитой от просмотра.
3. После запуска открыть страницу на компьютере и телефоне и проверить изображения, FAQ и кнопки.

## Загрузка через Railway CLI

Если CLI ещё не установлен на Mac, установите его командой `brew install railway` (или `npm i -g @railway/cli`). Затем из этой папки выполните:

```sh
railway login
railway up --new --name viktoria-site-review
```

Если хотите загрузить сайт в уже существующий проект Railway, сначала выполните `railway link`, затем `railway up` из этой папки и выберите отдельный сервис для сайта. Не загружайте эти файлы в сервис личного Telegram-помощника: сайт должен запускаться отдельно.

Railway автоматически использует `Dockerfile` в корне этой папки. Дополнительные переменные окружения не нужны: сервер читает `PORT`, который задаёт Railway, и слушает `0.0.0.0`.

После успешного деплоя откройте сервис в Railway и выберите **Settings → Networking → Public Networking → Generate Domain**. Только после этого появится публичная ссылка для Виктории. Если нужен закрытый просмотр, не создавайте публичный домен без отдельной настройки доступа.

## Локальная проверка

```sh
npm test
npm start
```

Откройте `http://localhost:3000`. Для проверки работы сервера доступен адрес `http://localhost:3000/healthz`.

## Ограничения текущей версии

- Сайт — черновик для согласования, не готовая клиентская воронка.
- Тексты, цены и право публикации фото ещё согласуются с Викторией.
- Переходы в Telegram и Instagram не подключены.
- Размещение на Railway и создание домена здесь не выполнялись; эта папка только подготовлена к загрузке.
