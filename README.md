# Сайт Виктории: рабочая папка для Railway

Обновлено: 5 октября 2026 года. Черновик уже развёрнут Кристиной на Railway: <https://victoriyatarot.up.railway.app/>. Это публичная ссылка для согласования с Викторией, а не утверждённый готовый сайт. Ответ `HTTP 200` подтверждал доступность страницы 4 октября, но не проверку всех экранов и действий посетителя. Исправление значков от 5 октября находится в этой локальной папке; на Railway оно ещё не загружено.

Эта папка содержит самостоятельную версию чернового сайта для согласования. В `public/` лежат HTML, CSS и изображения; `server.mjs` отдаёт эти файлы на порту, который задаёт Railway. Бот, база данных, API-ключи и платёжные интеграции в пакет не входят. Кнопки Telegram и Instagram пока не ведут в клиентские сценарии и честно показывают это при нажатии.

## Что проверить при согласовании с Викторией

1. Проверить тексты, цены и фотографию. Они взяты из предоставленных материалов и уже доступны по публичной ссылке, но отдельного утверждения Виктории пока нет.
2. Учесть, что домен уже публичный: страницу сможет открыть любой, у кого есть ссылка; метатег `noindex` не является защитой от просмотра.
3. Открыть страницу на компьютере и телефоне и проверить изображения, FAQ и кнопки. Такая визуальная проверка пока не зафиксирована.

Правки после замечаний Виктории вносить в эту папку. Макет в `output/viktoria-landing-draft/` и закрытый предварительный просмотр — история разработки, не источник дальнейших обновлений Railway. Перед повторной загрузкой проверить изменённую страницу локально и затем обновлять существующий сервис сайта, сохраняя его публичный адрес. Не загружать сайт в сервис личного Telegram-помощника.

## Загрузка через Railway CLI

Если CLI ещё не установлен на Mac, установите его командой `brew install railway` (или `npm i -g @railway/cli`). Для повторной загрузки из этой папки проверьте, что она связана с правильным проектом и именно сервисом сайта, затем выполните:

```sh
railway login
railway link
railway up
```

Команда `railway up --new` здесь не нужна: сайт уже развернут. При выборе сервиса не путайте его с сервисом личного Telegram-помощника.

Справка Railway: [связать папку с существующим проектом](https://docs.railway.com/cli/link) и [загрузить обновлённые файлы в сервис](https://docs.railway.com/cli/up).

Railway автоматически использует `Dockerfile` в корне этой папки. Дополнительные переменные окружения не нужны: сервер читает `PORT`, который задаёт Railway, и слушает `0.0.0.0`.

Публичный домен уже создан. После обновления откройте <https://victoriyatarot.up.railway.app/> и проверьте нужные изменения. Если потребуется закрыть доступ к черновику, это отдельное решение и настройка; `noindex` для этого недостаточен.

## Локальная проверка

```sh
npm test
npm start
```

Откройте `http://localhost:3000`. Для проверки работы сервера доступен адрес `http://localhost:3000/healthz`.

## Ограничения текущей версии

- Сайт — черновик для согласования, не готовая клиентская воронка.
- Тексты, цены и право публикации фото ещё согласуются с Викторией.
- Переходы в Telegram и Instagram не подключены.
- Размещение черновика на Railway выполнено; согласование Виктории и визуальная проверка после него ещё впереди.
